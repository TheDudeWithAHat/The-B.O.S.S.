# The-B.O.S.S.
This is code I have written for a robotic project that can play the left hand of a guitar.

This code is meant to go into a specific robot I built. 

Servos 0 and 1 control the finger by the 5th fret, 2 and 3 control the finger by the fourth fret and so on.
